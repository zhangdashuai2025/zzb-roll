# zzb-roll：Codex / WorkBuddy 双版本口播 B-roll Skill

`zzb-roll` 可以把口播视频与 SRT 字幕转成 Remotion 重点动效。它先提炼重点给用户审核，再生成可播放预览；用户确认后，才接入工程或导出。

## 先选择版本

| 你正在使用 | 应下载 | 说明文档 |
| --- | --- | --- |
| OpenAI Codex | `zzb-roll-codex-v1.1.0.zip` | 《Codex 版安装使用说明》 |
| 腾讯 WorkBuddy | `zzb-roll-workbuddy-v1.1.0.zip` | 《WorkBuddy 版安装使用说明》 |

两个 ZIP 不能混用。Codex 版包含本地安装脚本；WorkBuddy 版符合其上传 Skill 的目录和元数据结构，直接从技能页面导入。

## 能做什么

- 从长字幕中提炼短重点，不逐句复制。
- 生成文字、数字、比例、步骤、比较、CTA 和半透明卡片动画。
- 先审核文案和时间，再查看动画预览。
- 每段弹出音效独立开关和调音量，默认关闭。
- 导出带原视频的 MP4，或只含 B-roll 的透明 ProRes 4444 MOV。

## 需要准备

- 本地口播视频。
- 对应的 SRT 字幕。
- 一个可写的本地工作目录。
- Node.js 与 Remotion 工程环境；首次使用时可让 Codex 或 WorkBuddy 在获得授权后检查和安装依赖。

Skill 是工作流程与制作规范，不是双击即出片的软件。视频素材与渲染可以留在本机，但模型分析可能需要网络。

GitHub：<https://github.com/zhangdashuai2025/zzb-roll>

安装完成后，可以复制下面的通用任务说明：

```text
使用 zzb-roll。视频：这里填写视频完整路径；字幕：这里填写 SRT 完整路径。先提炼重点并给我审核原文、短语、出现时间和动画建议。审核通过后再生成可播放预览，不逐句复刻字幕，不覆盖现有工程，弹出音效默认关闭。
```
