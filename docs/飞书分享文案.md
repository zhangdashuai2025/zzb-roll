# zzb-roll：用字幕一键启动 Remotion 口播重点动效工作流

适合已有口播视频和 SRT 字幕、想做重点文字/数字/半透明卡片 B-roll 的创作者。它会先提炼重点给你审核，再做可播放预览；你确认后才接入工程或导出。不是逐句把字幕重复打一遍。

下载：请在此粘贴 `zzb-roll-v1.0.0.zip` 附件或 GitHub 仓库链接。

**准备：** 电脑安装 Node.js LTS 与 Codex；准备本地视频和同片 SRT。Remotion 在初次使用时由 Codex 按工程依赖安装/检查。此包是 Codex 技能，不是双击即出的成片软件。

**安装：** 解压附件，在解压目录打开终端，运行 `node install.mjs`，再重启 Codex。Windows 可在文件夹地址栏输入 `powershell` 打开终端。

**直接复制这句话给 Codex：**

> 使用 $zzb-roll。视频：`这里填视频文件完整路径`；字幕：`这里填 SRT 文件完整路径`。先按字幕提炼重点，给我审核原文、短语与出现时间。审核后再生成可播放的 Remotion 预览，不覆盖已有工程。B-roll 弹出音效默认关闭。

看完分镜可以逐条改字、取消或调时间。预览满意后说“应用到工程”，或说“导出透明 MOV，我要到剪映叠加”。透明层请用 ProRes 4444 MOV；普通 MP4 没有透明背景。

如果还没有 Remotion 工程，请额外告诉 Codex：“在我指定的工作目录新建 Remotion 工程”。生成方式因视频素材、字体和系统环境而异；不是保证对任何素材一步出片。
