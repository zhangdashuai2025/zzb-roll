# zzb-roll：Codex 版安装使用说明

## 1. 下载与安装

下载 `zzb-roll-codex-v1.1.0.zip` 并完整解压。电脑需要先安装 Node.js LTS。

Windows：在解压后的文件夹地址栏输入 `powershell` 并回车，然后运行：

```powershell
node install.mjs
```

macOS / Linux：在终端进入解压目录后运行：

```bash
node install.mjs
```

看到“zzb-roll 已安装”后，完全退出并重新打开 Codex。

## 2. 准备素材

准备本地视频与对应 SRT，最好放在同一文件夹。Windows 可按住 Shift 右键文件，选择“复制文件地址”。

## 3. 第一次使用

把路径替换成自己的，然后复制给 Codex：

```text
使用 $zzb-roll。
视频：D:\我的视频\口播视频.mp4
字幕：D:\我的视频\口播字幕.srt

请先合并语义段并提炼重点，给我审核原字幕、短文案、出现时间和动画建议。不要逐句复制字幕，不覆盖已有工程，暂时不要导出，弹出音效默认关闭。
```

没有 Remotion 工程时，加一句：“请在我指定的工作目录新建独立 Remotion 工程。”

## 4. 审核与预览

先修改或取消不合适的分镜，例如：“第 2 条改成半天完成，第 5 条取消，第 7 条延后 0.5 秒。”

确认后回复：

```text
分镜通过，按这版生成可播放预览。先不要覆盖正式工程，也不要导出。
```

预览中可以要求移动、缩放、改颜色、改时间，或只为某一段开启音效并设置音量。

## 5. 导出

完整成片：

```text
效果确认，保存工程并导出合成 MP4，保留原视频声音。
```

剪映透明叠加层：

```text
效果确认，只导出透明 B-roll，使用 ProRes 4444 MOV 和 Alpha，不包含 A-roll 背景和原声。
```

普通 H.264 MP4 不支持透明背景。

## 常见问题

- 找不到 `$zzb-roll`：确认安装成功后彻底重启 Codex。
- 视频不能播放：确认是完整本地路径；必要时转为 H.264 MP4。
- 看不到 B-roll：把播放头移动到对应时间，并确认已经从审核阶段进入预览阶段。
- 透明层黑底：检查是否为 ProRes 4444 MOV 且含 Alpha。
