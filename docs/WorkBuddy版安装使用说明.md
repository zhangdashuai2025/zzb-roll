# zzb-roll：WorkBuddy 版安装使用说明

## 1. 下载与导入

下载 `zzb-roll-workbuddy-v1.1.0.zip`。不要解压后重新打包，也不要上传 Codex 版 ZIP。

在腾讯 WorkBuddy 中依次打开：

> 专家·技能·连接器 → 技能 → 添加技能 → 上传技能

选择下载的 WorkBuddy ZIP。导入完成后，在“已安装”中确认 `zzb-roll` 已启用。

## 2. 创建任务和授权工作区

新建任务，选择 Coding 模式。添加一个独立、可恢复的本地文件夹作为工作区，并授权 WorkBuddy 读取视频/SRT、写入 Remotion 工程。首次测试建议使用 10–30 秒素材。

只授权本次需要的素材与工作目录，不要无必要地开放系统目录或私人文件夹。

## 3. 第一次使用

在对话中输入：

```text
使用 zzb-roll 技能。
视频：D:\我的视频\口播视频.mp4
字幕：D:\我的视频\口播字幕.srt

请先合并语义段并提炼重点，给我审核原字幕、短文案、出现时间和动画建议。不要逐句复制字幕，不覆盖已有工程，暂时不要导出，弹出音效默认关闭。
```

没有 Remotion 工程时，加一句：“请在当前授权工作区新建独立 Remotion 工程，并在安装依赖前向我确认。”

## 4. 审核与预览

先修改分镜，例如：“第 2 条改成半天完成，第 5 条取消，第 7 条延后 0.5 秒。”

确认后回复：

```text
分镜通过，按这版生成可播放预览。先不要覆盖正式工程，也不要导出。
```

WorkBuddy 会在授权工作区编写 Remotion 组件并启动本地预览。预览中可以要求移动、缩放、改颜色、改时间，或单独开启某段音效并设置音量。

## 5. 导出

完整成片：

```text
效果确认，保存工程并导出合成 MP4，保留原视频声音。
```

剪映透明叠加层：

```text
效果确认，只导出透明 B-roll，使用 ProRes 4444 MOV 和 Alpha，不包含 A-roll 背景和原声。
```

## 常见问题

- 上传后解析失败：确认使用 WorkBuddy 版 ZIP，内部应包含 `zzb-roll/SKILL.md`、`references` 与 `scripts`。
- 技能未触发：确认已安装并启用，然后在任务中明确写“使用 zzb-roll 技能”。
- 无法读取素材：在当前任务中授权视频、SRT 和工作目录。
- Node/Remotion 不存在：允许 WorkBuddy 在独立工作区检查并安装项目依赖。
- 透明层黑底：确认导出的是含 Alpha 的 ProRes 4444 MOV，不是普通 MP4。
