# 视觉语言与语义对齐

参考已获用户认可的口播叠加层：外层透明，内部各条为独立深色半透明圆角卡片；白色正文、蓝色 `#53baff` 表示方法/关系、黄色 `#ffd45c` 强调数字/行动。不要默认生成整片蓝底卡或逐字复刻字幕。

在 1920×1080 画布上，章节字约 23px、主标题约 54px、正文约 34–40px、辅助约 25px；卡片可用 `rgba(9,15,25,.78)`、18px 圆角与轻描边。数值只是起点，应按最终显示大小、人物位置和字幕安全区修正。竖屏应重新排版。

入场可从约 0.2 秒的小幅上移、0.94→1.015→1 弹性缩放开始；顺序列表按字幕语义时间进入，而不是所有条目一齐出现。每条有自己的相对帧差，上一条保留到组结束。最后一条应有足够停留。默认无额外音效；开启时每次出现可触发独立轻微 pop，单段音量由用户控制。

| 语义 | 可选表达 | 禁忌 |
| --- | --- | --- |
| 耗时/范围 | 两端点、刻度、数字强调 | 删除“可能”等限定条件 |
| 搜索/方法 | 搜索框、标签、箭头、步骤 | 虚构搜索结果 |
| 比例/数据 | 数字递增、圆环、柱状生长 | 无数据时编造百分比 |
| 分条观点 | 独立卡片按关键词顺序出现 | 末条刚出现就结束 |
| 比较/路径 | 两列或分支依次亮起 | 加入原文没有的优劣判断 |
| 行动请求 | 徽章、箭头、CTA 弹出 | 凭空承诺福利 |

示例短语仅用于说明设计；实际文案、时间和素材必须来自本次输入。重点词被 SRT 拆开时先合并语义，来源仍保留全部字幕 ID。
