# WorkBuddy 工程接入与验证

仅在用户明确要求“应用到工程”“替换”或“导出”时读取。

1. 确认当前预览就是用户批准的版本，备份工程 JSON、旧组件和相关素材。不要修改旧组件中的硬编码文字，导致历史项目画面变化。
2. 新场景使用独立 ID 或命名空间。保存结构要同时通过前端类型、后端校验与重新读取，避免 Schema 静默删除新字段。
3. Player、编辑器、合成 MP4 与透明 MOV 必须引用同一场景组件和数据。保存 `enabled`、起止帧、位置、尺寸、文案、样式、`soundEnabled` 与 `soundVolume`。
4. 验证拖动画布只改变位置，缩放把手才改变尺寸；移动播放头、移动片段和裁切片段互不混淆。
5. 重启本地服务后检查刷新、预览返回编辑器、自动保存和再次打开。导出前等待最新保存完成。
6. MP4 检查画面、原声与时长；透明 MOV 检查 ProRes 4444、Alpha 和透明区域。没有完成整片检查时明确说明验证范围。
